FLEX Lexer Assignment Files

Files:
- lexer.l: FLEX source file
- input.txt: sample source code to analyze
- expected_output.txt: expected token output

Run on Linux/Ubuntu:
1. Install tools: sudo apt install flex gcc
2. Generate C source: flex lexer.l
3. Compile: gcc lex.yy.c -o lexer
4. Run on the sample input: ./lexer < input.txt
5. Save the output: ./lexer < input.txt > output.txt

The generated lex.yy.c file is created by the flex command. It is not included here because it should be generated by your installed FLEX version. If your teacher requires it, run step 2 and submit the generated file too.
